# TP2_bertone_POD
Análisis de los resultados de los Grand Prix y Sprints de Formula 1 en la temporada 2025.

Objetivo:
Permitir comparar el rendimiento de constructores(equipos) y pilotos por carrera y a lo largo de la temporada.

Requisitos:
Python 3.10
https://www.python.org/downloads/

Repositorio Datasets:
URL: https://www.kaggle.com/datasets/makslypko/f1-race-result-2025
